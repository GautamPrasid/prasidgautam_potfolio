## Deploy the portfolio to Vercel

1. Push the application repository to GitHub.
2. Import the repository into [Vercel](https://vercel.com/).
3. Add `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, and `NEXT_PUBLIC_SITE_URL` under the Vercel project's environment variables. Set the site URL to the production origin.
4. Deploy the project. Vercel detects and builds the Next.js application.

Ensure the Supabase schema is applied and at least one administrator user is registered in `public.admins` before using the admin dashboard in production.

## Host these docs with Mintlify

The Mintlify configuration is [`docs.json`](https://github.com/GautamPrasid/prasidgautam_potfolio/blob/main/docs.json) at the repository root. In the Mintlify dashboard, connect this GitHub repository and use the repository root as the docs directory. Mintlify publishes the MDX pages and can deploy updates when changes are pushed.

To preview the docs locally, run the Mintlify development server from the repository root:

```bash
npx mint dev
```

This command uses the Mintlify CLI without adding it to the portfolio's application dependencies.
