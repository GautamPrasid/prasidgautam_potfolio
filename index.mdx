## Project overview

The portfolio is built with Next.js 14, TypeScript, Tailwind CSS, Framer Motion, and Supabase. The public site reads profile and portfolio content from Supabase; authorized administrators edit it through the `/admin` dashboard.

The documentation is separate from the Next.js application. Mintlify reads the root `docs.json` and the MDX pages in this repository.
